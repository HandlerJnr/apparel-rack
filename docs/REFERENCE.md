# Provenance

Baseline reference: Hangtime Apparel, https://ecom-apparel.whop.site/, inspected 26 October 2026.

The current prototype retains the reference's page layout, copy, garment imagery, rail geometry and physics/rendering implementation. Reference trackers and injected browser elements were removed. It remains a private design study, without a claimed licence or authorship over the reference material.

Custom development in this project includes spring-based cloth motion in the Drop grid, delayed hem movement, touch hold/horizontal-drag interaction, click suppression after play gestures, vertical-scroll preservation, a touch discovery hint, modular source organisation and a preview-first workflow.
